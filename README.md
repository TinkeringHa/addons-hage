# 哈哥应用商店

## 关于

本商店主要将国外知名的 HA 应用汉化，谢谢大家的支持。

## 安装方法

### 方法一（一键添加仓库）

[![一键添加本应用商店到 Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FTinkeringHa%2Faddons-hage)

点击上方按钮，在跳转页点击 **打开链接**。

### 方法二（手动添加）

1. 进入 HA：**设置 → 应用 → 安装应用 → ︙ → 仓库 → 添加**。
2. 粘贴仓库地址 `https://github.com/TinkeringHa/addons-hage`，点击 **添加**。
3. 在应用商店中找到 **Add-ons by hage**，安装 **Node-RED 汉化版**。
