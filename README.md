# 哈哥应用商店

## 关于

本商店主要将国外知名的 HA 应用汉化，谢谢大家的支持。

## 安装方法

### 方法一（推荐 · 一键添加仓库）

点击下方按钮，会打开 [My Home Assistant](https://my.home-assistant.io/) 中间页；在页面中点击 **「打开链接」**，即可跳转到你的 HA 实例并添加本应用商店仓库（仓库地址已预填）。

[![一键添加本应用商店到 Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FTinkeringHa%2Faddons-hage)

**使用说明：**

1. 需要 Home Assistant **2021.3** 及以上，并已启用 [**my** 集成](https://www.home-assistant.io/integrations/my/)。
2. 首次使用请在 [My Home Assistant](https://my.home-assistant.io/) 中保存你的 HA 访问地址（数据仅存在浏览器本地）。
3. 仓库添加成功后，进入 **设置 → 应用 → 应用商店**，在 **Add-ons by hage** 下找到 **Node-RED 汉化版** 并安装。

如需自行生成或修改链接，可使用官方工具：[Create a link](https://my.home-assistant.io/create-link/)（选择 **Add repository**，仓库 URL 填 `https://github.com/TinkeringHa/addons-hage`）。

### 方法二（手动添加）

1. 进入 HA：**设置 → 应用 → 安装应用 → ︙ → 仓库 → 添加**。
2. 粘贴仓库地址 `https://github.com/TinkeringHa/addons-hage`，点击 **添加**。
3. 在应用商店中找到 **Add-ons by hage**，安装 **Node-RED 汉化版**。
